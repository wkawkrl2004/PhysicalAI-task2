# Dofbot 분리수거 Task 전체 파이프라인

> 검증 결과(오류·제한 사항)는 [REVIEW.md](REVIEW.md) 참고. 아래 내용에 일부 반영됨.

## 0. 과제 요약
- **물체**: 종이류(A4 뭉치, 종이팩), 비닐류(초코파이 봉지 크기 이하), 플라스틱류(야쿠르트 병, 요플레 용기) 각 2개, 총 6개
- **배치**: Dofbot 정면 가운데 기준 반지름 23cm 호 안에 무작위
- **분리 위치**: 색종이 (예: 파랑=종이, 초록=비닐, 빨강=플라스틱). 놓인 쓰레기는 매번 제거됨
- **Test 1**: 우리 조 물체 세트 / **Test 2**: 다른 조 세트 중 하나를 당일 무작위 지정
- **평가**: 정확도 k/N (맞는 색종이 위에서 그리퍼를 놓으면 성공), 완료 시간 (제한 약 6분)

## 1. 전체 구조

```
┌─────────────── 실행 루프 (제한 시간 6분) ───────────────┐
│  ① 인식   메타 뷰 → YOLO 검출 → 클래스 + 픽셀 (u,v)       │  ← 지도학습
│     ↓     호모그래피 → 책상 좌표 (x,y)                    │
│  ② 접근   IK(+보정) → 물체 위 7cm 접근 자세              │  ← 기구학
│     ↓                                                   │
│  ③ 집기   손목 카메라 + 관절값 → BC/ACT 정책 → 하강·집기   │  ← 모방학습
│     ↓     (집기 높이, 그리퍼 값 = RL로 최적화)           │  ← 강화학습
│  ④ 확인   그리퍼 각도 + 메타 뷰로 성공 여부 판정          │
│     ↓                                                   │
│  ⑤ 놓기   클래스별 고정 자세 → 색종이 위에서 그리퍼 열기    │  ← 스크립트
│     ↓                                                   │
│  HOME 복귀 → ①로 (남은 물체 없으면 종료)                  │
└─────────────────────────────────────────────────────────┘
```

**원칙**
- 학습은 실제로 어려운 부분(인식, 집기)에만 쓰고, 나머지는 수식과 고정 자세로 처리한다.
- 먼저 스크립트 집기로 끝까지 돌아가는 기본 시스템을 만들고, 그다음 집기 부분을 학습 정책으로 교체한다.

## Phase D. 보정: 픽셀 → 책상 좌표 → 관절값

### D1. 호모그래피 (픽셀 → 책상 cm)
- 좌표계: 원점 = J1 회전축 바로 아래, x축 = 로봇 정면, y축 = 왼쪽
- 작업 영역 = 중심 (d0, 0), 반지름 23cm (d0 = J1 축 ↔ 베이스 앞 가운데 거리). J1 축 기준 최대 거리는 23 + d0
- 책상에 표시 6~9개를 두고 실제 좌표를 자로 측정 (경계 + 내부)
- 팔을 HOME에 둔 상태에서 메타 뷰의 표시 픽셀 기록 → `cv2.findHomography` → `pix2xy(u, v)`
- 렌즈 왜곡이 크면 먼저 체스보드로 왜곡 보정(`cv2.calibrateCamera`)

### D2. 기구학 (IK + 보정)
- **FK**: 서보값 → 그리퍼 끝 (x, y, z)
- **IK**: J1 = 방향 각도 θ, J2~J4 = 3링크 평면 IK (피치 지정 시 닫힌 해)
  - 기본은 수직 집기(피치 180°). 도달 불가 시 피치를 5°씩 세우며(최대 90°까지) 해를 찾음 (`ik_auto_pitch`)
  - J1에도 SIGN·OFFSET 적용
- **보정**: 실측 점 15~25개(경계 포함)를 직접 집는 자세의 서보값을 기록 → `scipy.optimize.least_squares`로 OFFSET(필요 시 링크 길이)을 FK 오차가 최소가 되도록 맞춤
- **대안**: J1 = θ의 1차 함수, J2~J4 = 거리 r에 대한 1차원 보간

### D3. 검증
- 보정에 쓰지 않은 표시 10곳에서 "메타 뷰 검출 → IK 이동" 후 오차 측정

✅ 완료 기준: 평균 오차 1cm 이하, 최대 1.5cm 이하

## Phase F. 집기

### F1. 스크립트 집기 (먼저 완성)
1. IK로 물체 위 7cm 접근 자세 이동, J5를 물체 방향에 맞춤
2. 손목 카메라로 물체 중심 검출
3. 물체가 화면 가운데에 오도록 x, y 미세 보정 (비주얼 서보잉 2~3회)
4. 클래스별 집기 높이로 하강 → 그리퍼 닫기 → 10cm 들어올리기

### F2. 모방학습 정책 (BC/ACT)
정책은 **접근 자세에서 시작**한다. 손목 카메라에 대상만 크게 보이므로 "무엇을 집을지" 고민할 필요가 없고 데이터 양도 줄어든다.

| 항목 | 내용 |
|---|---|
| 입력 | 손목 이미지(224×224), 현재 관절값 6개, 클래스 one-hot. (선택) 메타 뷰 대상 주변 crop |
| 출력 | 앞으로 k=10스텝의 관절 목표값 (action chunking) |
| 모델 | 1단계 ResNet18(사전학습)+MLP → 2단계 ACT |
| 데이터 수집 | `data_collect.ipynb` 확장: 카메라 2대, 5~10 FPS, 에피소드 단위, 서보 버스 접근에 Lock, 조이스틱을 IK로 연결해 x/y/z 직교 조작 |
| 에피소드 흐름 | 스크립트로 접근 자세 자동 이동 → 사람이 조이스틱으로 하강·집기·들어올리기 → 종료 버튼 |
| 데이터 양 | 클래스별 50~100 에피소드 (총 150~300) |
| 행동 라벨 | 조이스틱 스레드가 보낸 목표 각도 기록 |
| DAgger | 정책 실패 상황에서 사람이 복구한 시연 추가 |
| 학습 | PC/Colab, 이미지 증강(색, 작은 이동) |
| 추론 | 라즈베리파이 CPU가 느리면 노트북 GPU 추론 + 소켓으로 각도 전송 |
| 안전장치 | 출력 clamp(Phase C 범위), 스텝당 최대 변화량 제한, FK로 책상 아래 출력 차단 |

데이터 형식:
```
data/episodes/ep_0001/
  ├─ cam_wrist/00000.jpg ...
  ├─ cam_top/00000.jpg ...
  └─ labels.csv  # episode, frame_id, timestamp, m1..m6(목표), r1..r6(실측), class, phase
```

### F3. 강화학습: 집기 파라미터 최적화
| 항목 | 내용 |
|---|---|
| 상태 | 클래스, 거리 r, bbox 크기·방향 |
| 행동 | 집기 높이 보정(Δz), 그리퍼 닫힘 값, J5 보정, x/y 미세 보정 |
| 보상 | 성공 1 / 실패 0. 자동 판정: 그리퍼가 끝까지 닫히지 않음 + 들어올린 뒤 메타 뷰 원래 위치에서 물체가 사라짐 |
| 알고리즘 | 클래스별 CEM 또는 Thompson Sampling 밴딧 |
| 자동 리셋 | 실패 시 물체가 그대로 남음, 성공 시 작업 영역 안 무작위 위치에 떨어뜨림 |
| 규모 | 클래스별 약 100회 (1회 15초, 총 1~1.5시간) |

(여유가 있으면) MuJoCo + PPO로 reaching 정책을 학습해 실제 로봇에 적용.

✅ 완료 기준: 클래스별 집기 성공률 85% 이상, 물체당 집기 10초 이하

## Phase H. 통합 실행 (상태 머신)

```python
T_LIMIT = 360 - 15
start = time.time()
fail_count = defaultdict(int)

while time.time() - start < T_LIMIT:
    move(HOME); wait_settle()                   # move()는 이동 시간만큼 sleep 포함
    dets = filter_workspace(yolo(cam_top_read()))
    if not dets: break
    dets = [d for d in dets if fail_count[match_key(d)] < 3]   # 좌표 3cm 이내 = 같은 물체
    if not dets: break
    tgt = min(dets, key=lambda d: d.r)          # 가까운 것부터
    x, y = pix2xy(*tgt.center)

    sol, pitch = ik_auto_pitch(x, y, APPROACH_Z)
    if sol is None: fail_count[match_key(tgt)] += 1; continue
    move(sol + [j5_for(tgt), GRIP_OPEN])

    grasp(tgt)               # F1 스크립트 or F2 정책 (+F3 파라미터)
    lift()
    if not grasp_success(): fail_count[match_key(tgt)] += 1; continue

    cls = tgt.cls if tgt.conf > 0.7 else wrist_classify()
    move(POSES[f'DROP_{cls.upper()}']); open_gripper()
```

**시간 예산 (물체 1개)**: 검출 1초 + 접근 3초 + 집기 8초 + 놓기 4초 + 복귀 3초 ≈ 20초 → 6개 약 2분

| 실패 상황 | 대응 |
|---|---|
| 물체를 놓침 | 다시 검출해서 재시도 (최대 3번) |
| 도달 불가 위치 | 피치를 세워 IK 재시도 → 실패 시 건너뛰기 |
| 이동 중 떨어뜨림 | 다음 루프에서 다시 검출 |
| 검출 신뢰도 낮음 | 들어올린 뒤 손목 카메라로 재분류 |
